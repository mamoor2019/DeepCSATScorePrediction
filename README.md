This project focuses on predicting Customer Satisfaction (CSAT) scores for an e-commerce platform, Shopzilla, using a Deep Learning Artificial Neural Network (ANN).

Customer satisfaction is an important factor in customer retention, loyalty, service quality, and business growth. The project uses historical customer interaction and service data to identify patterns associated with customer satisfaction and develop a machine learning model that can predict CSAT scores for new interactions.

The project covers the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, class imbalance handling, ANN model development, evaluation, and business insights.
